# Engineer Growth Roadmap

自分専用の成長ログ。知識を蓄積するのではなく、**説明できることを増やす**ためのリポジトリ。

## 目的

- 副業獲得
- 市場価値向上
- 技術理解
- 面接突破

## 進め方

```
質問
  ↓
回答
  ↓
レビュー
  ↓
理解不足発見
  ↓
学習
  ↓
Todo API 改善
  ↓
GitHub 更新
```

## ディレクトリ構成

| ディレクトリ | 内容 |
|---|---|
| `roadmap/` | 目標・学習計画・進捗チェックリスト |
| `interview/` | 技術面接の Q&A（自己回答 → 改善版） |
| `portfolio/` | 成果物レビューと改善タスク |
| `notes/` | 補助メモ・リンク集 |

## 伴走フロー（Step 1〜5）

### Step 1 面接（15〜30 分）

質問に自分の言葉で回答する。

### Step 2 レビュー

回答を添削し、理解の穴を特定する。

### Step 3 学習

不足している知識を整理して学ぶ。

### Step 4 実装

Todo API へ反映できるなら反映する。

### Step 5 ドキュメント更新

このリポジトリを更新する。

## 目指す状態

100 問を終えたときには、次の 3 つがつながった状態を目指す。

- 面接で答えられる知識
- GitHub で見せられる成果物
- 実務で応用できる理解
