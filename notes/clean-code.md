# Clean Code

面接・コードレビューで語れるようになるためのメモ。

## 命名

- 変数名・関数名は「何をするか」が分かるように
- 略語より明示的な名前（`usr` より `user`）
- boolean は `is`, `has`, `can` で始める

## 関数

- 1 関数 1 責務
- 引数は少なく（3 つ以上は分割を検討）
- 副作用を明示する

## コメント

- 「何を」ではなく「なぜ」を書く
- コードで表現できることはコメントにしない

## 面接で聞かれそうな問い

- [ ] リファクタリングの判断基準は？
- [ ] テストしやすいコードの特徴は？
- [ ] 早期 return を使う理由は？
