### 改善版

Javaがオブジェクト指向言語であるというのは、データとそのデータを操作する処理をオブジェクトとしてまとめ、オブジェクト同士を連携させてシステムを構築できるという意味です。

それぞれのオブジェクトに責務を持たせることで、変更の影響範囲を限定し、保守やテストをしやすくできます。

Todo APIでは、Todoを表すEntity、HTTPリクエストを受けるController、業務処理を行うService、データアクセスを行うRepositoryに責務を分けている部分に、この考え方が現れています。

- オブジェクトに責務を持たせるとは、そのオブジェクトに関係する判断・ルール・処理を担当させること
- 各オブジェクトは自分自身に関するルールを担当し、Serviceは複数のオブジェクトを使ってユースケース全体を調整する
- 責務ごとに処理がまとまるため、変更箇所を見つけやすく、変更の影響範囲を限定できる
- 責務が分かれていれば、対象ごとに単体テストしやすくなる

### 改善版

- **カプセル化**: データとそのデータを操作する処理をクラスにまとめ、内部状態を外部から直接変更できないようにすることです。変更方法をメソッド経由に限定することで、不正な状態を防ぎます。

- **ポリモーフィズム**: 共通のインターフェースや親クラスを通して、実装の異なるオブジェクトを同じ方法で扱える性質です。例えば、通知処理をインターフェースにしておけば、呼び出し側を変えずにメール送信やSlack送信へ実装を切り替えられます。

Springでは、Serviceがインターフェースに依存し、具体的な実装をDIで受け取る構造などに応用されています。

## Q4（HTTP）

### HTTPメソッド（GET・POST・PUT・PATCH・DELETE）の違いを説明してください

さらに、Todo APIではどこで使ったかまで説明してください。

### 自己評価
🟡

### 自分の回答
- GETは取得系のAPIで使われる
- POSTは登録系のAPIで使われる
  - bodyに必要な情報を与えることができる
- PUTは更新系のAPIで使われてる
- PATCHはわからない
- DELETEは削除系のAPIで使用される

### 改善版

GETはリソースの取得、POSTは新しいリソースの作成、PUTは指定したリソース全体の置換、PATCHはリソースの一部更新、DELETEはリソースの削除に使います。

Todo APIでは、一覧・詳細取得にGET、Todo作成にPOST、全体更新にPUT、一部項目だけの更新にPATCH、削除にDELETEを使います。

安全とはリソースの状態を変更しない性質、冪等とは同じ操作を複数回実行してもサーバー上の最終状態が同じになる性質です。GETは安全かつ冪等、PUTとDELETEは冪等、POSTは通常どちらでもありません。PATCHの冪等性は更新方法によります。

### 学習した要点

- GETはリソースを取得する
- POSTは新しいリソースの作成などに使う
- PUTは指定したリソース全体を置き換える
- PATCHは指定したリソースの一部分を変更する
- DELETEはリソースを削除する
- 安全性は、対象リソースの状態変更を目的としない性質
- 冪等性は、同じリクエストを1回実行しても複数回実行しても、サーバー上の最終状態が同じになる性質

| メソッド | 安全 | 冪等 | 理由 |
|---|---|---|---|
| GET | はい | はい | 取得を目的とし、繰り返してもリソースを変更しない |
| POST | いいえ | 通常はいいえ | 繰り返すと複数のリソースが作成される可能性がある |
| PUT | いいえ | はい | 状態を変更するが、同じ内容で繰り返しても最終状態は同じ |
| PATCH | いいえ | 実装による | 値の置換なら冪等にできるが、加算などは冪等にならない |
| DELETE | いいえ | はい | 状態を変更するが、繰り返しても削除済みという最終状態は同じ |

### 再回答
- 各HTTPメソッドの用途
  - GET
    - リソースの取得
  - POST

### 改善版

| コード | 意味 | Todo APIで返す場面 |
|---|---|---|
| 200 OK | リクエスト成功 | Todo一覧・詳細の取得、更新成功 |
| 201 Created | リソース作成成功 | Todoの新規作成 |
| 400 Bad Request | リクエストが不正 | 必須項目不足、形式不正、バリデーションエラー |

- スタックトレースやDB詳細は、情報漏えいによって攻撃のヒントを与えるため返さない
